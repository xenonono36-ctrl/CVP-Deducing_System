Bézout's Identity & Inverse

For non-zero $a, b$, integers $s, t$ exist such that:

gcd(a, b) = s·a + t·b

Use Extended Euclidean Alg to find inverse $x$ where $a·x \equiv 1 \pmod m$.

Fermat's Little Theorem

If $p$ is prime and $p \nmid a$:

a^(p-1) ≡ 1 (mod p)
a^p ≡ a (mod p)

RSA Encryption Protocol

Key Generation & Ciphering steps:

n = p · q
φ(n) = (p - 1)(q - 1)
d · e ≡ 1 (mod φ(n))
Enc: C = M^e mod n | Dec: M = C^d mod n

Generalized Pigeonhole

If $N$ items go into $k$ boxes, at least 1 box gets:

⌈ N / k ⌉ objects

Handshaking Lemma

Sum of vertex degrees in undirected graph:

Σ deg(v) = 2 · |E|

Key Note: An even number of vertices have odd degrees.

Eulerian Conditions

For connected graphs:

Euler Circuit: ALL vertices have EVEN degree
Euler Path: EXACTLY 2 vertices have ODD degree

Full m-ary Tree Formulas

Vertices ($n$), Internal nodes ($i$), Leaves ($l$):

n = m · i + 1
l = (m - 1)i + 1

Tree Traversals

Standard node processing order:

Preorder: Root → Left → Right
Inorder: Left → Root → Right
Postorder: Left → Right → Root
